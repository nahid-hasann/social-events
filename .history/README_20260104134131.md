# 🌍 SocialEvents — Community Social Development Platform

**SocialEvents** is a community-driven event management web application where users can create, join, and track social development events in their local area. It features role-based access control (Admin/User) and a comprehensive dashboard system.

## ✨ Key Features
✅ **Authentication:** Secure Register & Login using Firebase Auth.  
✅ **Role-Based Dashboard:** Separate dashboards for **User** and **Admin**.  
✅ **Event Management:** Create, Update, and Delete social events.  
✅ **Event Participation:** Users can join events and track them in "My Joined Events".  
✅ **Admin Powers:** Admins can manage all users and events from the dashboard.  
✅ **Search & Filter:** Find events easily by category or search by name.  
✅ **Demo Login System:** Easy access for testing User and Admin features.  
✅ **Interactive UI:** Framer Motion animations, Toasts, and SweetAlerts.  
✅ **Theme Support:** Dark/Light mode toggle with local storage persistence.  
✅ **Pages:** Includes Home, About Us, Contact Us, and Dashboard pages.  
✅ **Responsive:** Fully optimized for Mobile, Tablet, and Desktop devices.

## 🔐 Private & Admin Routes
Certain pages are protected and require specific access levels:

**User Routes:**
- `/create-event` → Create new events
- `/dashboard/user-home` → User Dashboard
- `/dashboard/joined-events` → View joined events
- `/dashboard/my-events` → Manage own events

**Admin Routes:**
- `/dashboard/admin-home` → Admin Dashboard (Overview)
- `/dashboard/all-users` → Manage Users (Make Admin/Delete)
- `/dashboard/manage-events` → Manage All Events

## 🧠 How It Works
1. **Register/Login:** Users must log in to create or join events.
2. **Dashboard:** - **Users** see their joined and created events.
   - **Admins** see system-wide statistics and can manage users.
3. **Join Events:** Clicking "Join" adds the user to the event participant list.
4. **Theme:** Toggle between dark and light mode from the navbar.
